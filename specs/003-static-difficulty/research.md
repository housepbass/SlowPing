# Independent target research

The active game stays with static IPv4 routing. The owner retired the TE experiment and requested a substantial difficulty increase at each level. Three authored levels now expose1,10,16editable route slots across3,6,8routers.

Proof data: [path-proof.json](path-proof.json), generated by tools/author-levels.py using independent Python graph search. Cross-check: tests/network.test.js enumerates local route-table alternatives with independent prefix matching, then TTL-bounded simple paths. Global configuration enumeration is unnecessary and would grow exponentially. A successful packet cannot repeat a router under deterministic destination-only forwarding; a repeated router repeats the same next hop until TTL expires.
